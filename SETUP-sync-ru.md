# Сервер приложения: настройка владельцем (один раз, ~10 минут)

Пользователи ничего не настраивают: они только открывают приложение, регистрируются по почте и вступают в семью по ссылке или 6-значному коду. Сервер ставите **вы, один раз**, для всех.

## Часть 1. Сервер в Google

1. Откройте https://script.google.com под своим Google-аккаунтом → **Новый проект**.
2. Удалите всё, что там есть, и вставьте содержимое `server/Code.gs`. Сохраните.
3. **Начать развертывание → Новое развертывание** → шестерёнка → **Веб-приложение**. Выполнять как: **Я**. Доступ: **Все**.
4. **Развернуть**, разрешите доступ (Drive, отправка почты, внешние запросы). При предупреждении «не проверено»: «Дополнительно» → «Перейти».
5. Скопируйте **URL веб-приложения** (оканчивается на `/exec`).

> Изменили `Code.gs`? **Управление развертываниями → карандаш → Версия: Новая версия → Развернуть**, иначе работает старый код. Обновление с версии 2: старые семьи (по коду-приглашению) не переносятся, нужна регистрация заново.

## Часть 2. Вписать адрес сервера в приложение

Откройте файл `config.js` в папке приложения и вставьте URL:

```js
window.CL_CONFIG = { serverUrl: "https://script.google.com/macros/s/.../exec" };
```

Загрузите обновлённый `config.js` на хостинг (GitHub). Всё: у пользователей в приложении сами появятся регистрация и семья. Пока адрес пустой, приложение работает без аккаунтов, данные только на телефоне.

## Как пользователи подключаются (до 2 минут)
1. Первый человек регистрируется: фамилия, имя, дата рождения, пол, почта, пароль, код из письма. Семья создаётся автоматически.
2. Раздел **Семья** → **Отправить ссылку** (или назвать 6-значный код).
3. Второй человек открывает ссылку, регистрируется — и сразу в семье. Если уже зарегистрирован, просто открывает ссылку и подтверждает. Можно и по ID (`CL-XXXX-XXXX`): **Семья → Пригласить по ID**.

Код живёт 7 дней, его можно обновить кнопкой «Новый код». Убрать человека может создатель семьи. Выйти можно самому.

## Что хранится и кто что видит
- Всё лежит в вашем Google Drive, папка `ComfortableLifeSync` (аккаунты, семьи).
- Пароль на сервер не уходит: телефон отправляет только результат PBKDF2, сервер хеширует его ещё раз.
- Общие заметки и события шифруются на телефоне ключом семьи, **но ключ хранит сервер** (так вход в семью занимает минуты, без фраз-паролей). Значит, вы как владелец сервера технически можете прочитать общие данные. Личное (без галочки «Для семьи»), спорт и здоровье остаются только на телефоне. Скажите об этом пользователям (в приложении есть пометка).
- Фамилию, имя, возраст и пол видят участники одной семьи.

## Ограничения бесплатного Google
- Письма с кодами: примерно 100 в день с обычного аккаунта (в Google Workspace больше). Это потолок регистраций в сутки. Если письма не доходят, проверьте «Спам».
- Apps Script отвечает за 1–3 секунды: для семей это нормально, для тысяч пользователей нужен свой сервер.

## Часть 3. ИИ-ассистент (по желанию): GigaChat или Claude

Ассистент выполняет команды без сервера, а на «как дела», «напиши сочинение» отвечает ИИ через ваш сервер. Если заданы оба ключа, используется GigaChat, а при его сбое Claude.

**GigaChat (Сбер), по умолчанию для России**
1. https://developers.sber.ru/studio → войдите (Сбер ID) → создайте проект **GigaChat API** → **Получить ключ авторизации** (скопируйте «Authorization key»; он показывается один раз).
2. Apps Script → **Настройки проекта** → **Свойства скрипта** → **Добавить**: `GIGACHAT_AUTH` = ключ. По желанию: `GIGACHAT_SCOPE` (по умолчанию `GIGACHAT_API_PERS`; для юрлиц `GIGACHAT_API_B2B`/`GIGACHAT_API_CORP`), `GIGACHAT_MODEL` (по умолчанию `GigaChat`).
3. Для физлиц есть бесплатный лимит токенов, дальше платно. Условия смотрите у Сбера.
4. Важно: серверы Сбера используют сертификат Минцифры. Сервер сначала пробует обычное подключение, при ошибке сертификата повторяет без проверки цепочки. Если из Google до серверов Сбера не достучаться (возможны блокировки по региону), ассистент автоматически уйдёт на Claude (если ключ есть) или скажет, что ИИ недоступен.

**Claude (для США и как запасной вариант)**
1. Ключ на https://console.anthropic.com (платно, по расходу).
2. Свойство скрипта `ANTHROPIC_API_KEY` = ключ. По желанию `AI_MODEL` (по умолчанию `claude-haiku-5-5`).

Лимит: 40 сообщений в сутки на аккаунт (`AI_DAILY` в `Code.gs`). Без ключей ассистент отвечает, что ИИ не подключён, команды работают. Тексты вопросов уходят с вашего сервера в Сбер или Anthropic: упомяните это в политике приватности.

## Часть 4. Яндекс Умный дом: вход одной кнопкой

Человек нажимает «Войти через Яндекс», входит в свой аккаунт, выбирает свои устройства. Токены вручную не вводятся. Токен каждого человека хранится на сервере в его аккаунте, семья устройства друг друга не видит.

Один раз владельцу:
1. https://oauth.yandex.ru/client/new → платформа **Веб-сервисы**. **Callback URI** = адрес вашего сервера (тот же `.../exec`, что в `config.js`). Доступы: **iot:view** и **iot:control**.
2. Скопируйте **ID** и **Пароль** приложения.
3. Apps Script → Свойства скрипта: `YANDEX_CLIENT_ID` = ID, `YANDEX_CLIENT_SECRET` = пароль. Если Callback URI отличается от адреса развёртывания, добавьте `YANDEX_REDIRECT` с ним же.
4. После изменения кода создайте **новую версию развёртывания** (Управление развёртываниями → Изменить → Новая версия): иначе приложение будет ходить к старому коду.

Работает с аккаунтами, где уже есть «Дом с Алисой». Работу с настоящим Яндексом мы не проверяли (только заглушкой): первый вход сделайте сами и напишите, что не так. Для публичного запуска Яндекс может потребовать модерацию приложения.

## Скорость синхронизации
Телефон каждые 8 секунд (20, если в семье один) проверяет только номер версии, и скачивает данные лишь при изменении. Свои правки уходят через 0,8 с. Итого общая запись доходит до другого телефона за ~1–10 секунд при открытом приложении. В фоне опрос остановлен. Для мгновенной доставки (как в мессенджерах) нужен собственный сервер.

## Салют (Сбер)
У Сбера нет публичного API, через который сторонние приложения управляют устройствами пользователя (доступ открыт производителям устройств). Поэтому в приложении Салют отмечен как «в разработке». Подключение возможно через партнёрство со Сбером (smarthome@sberdevices.ru).

## Если что-то не работает
- «Нет связи с сервером»: проверьте URL в `config.js` и доступ «Все».
- Не приходит код: «Спам», дневной лимит писем, минута между запросами.
- «Сессия закончилась»: войдите снова (после смены пароля все сессии закрываются).
